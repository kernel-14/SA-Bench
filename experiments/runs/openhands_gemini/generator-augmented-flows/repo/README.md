
# Improving Consistency Models with Generator-Augmented Flows

This repository contains a faithful reproduction of the paper "Improving Consistency Models with Generator-Augmented Flows".

## Codebase Structure:

- `config.py`: Contains all hyperparameters and configuration settings for training and evaluation.
- `data.py`: Handles dataset loading, preprocessing, and augmentation.
- `layers.py`: Defines basic building blocks and custom layers for the neural networks.
- `modules.py`: Implements higher-level neural network modules, potentially including the Consistency Model architecture.
- `model.py`: Integrates the modules to form the complete Consistency Model and related components.
- `train.py`: Contains the main training loop, including loss functions, optimization, and evaluation logic.
- `requirements.txt`: Lists all Python dependencies required to run the codebase.
