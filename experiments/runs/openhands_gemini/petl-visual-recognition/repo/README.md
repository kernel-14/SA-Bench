
# PETL-Visual-Recognition

This repository reproduces the core contributions of the paper "Lessons and Insights from a Unifying Study of Parameter-Efficient Fine-Tuning (PEFT) in Visual Recognition".

The codebase is structured as follows:

- `configs/`: Configuration files for models, training, and PEFT methods.
- `data/`: Contains data loading and preprocessing scripts.
- `models/`: Defines the Vision Transformer backbone and various PEFT modules.
- `training/`: Includes the training and evaluation loops.
- `utils/`: Utility functions.
- `requirements.txt`: Python dependencies.
