# Pyramidal Flow Matching Reproduction

## Description
This repository replicates the research paper titled "Pyramidal Flow Matching for Efficient Video Generative Modeling".

### Core Contributions Reproduced
1. Pyramidal Flow Matching algorithm for spatial and temporal hierarchical modeling of videos.
2. Unified training objective leveraging Diffusion Transformers (DiT).
3. Autoregressive video generation with temporal pyramids.
4. Efficient evaluation using VBench and EvalCrafter frameworks.

### Directory Overview
- `src/`: Contains implementation-related source code.
- `config/`: Includes training configurations.
- `scripts/`: Scripts for preprocessing, evaluation, and visualization.
- `data/`: Simulation/test data for examples.
