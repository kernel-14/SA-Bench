# Linearization Turns Neural Operators into Function-Valued Gaussian Processes (LUNO)
## Scope

This repository aims to replicate the main contributions of the LUNO framework presented in the paper. Our focus is on implementing the theoretical constructs, practical algorithms, and validation tests associated with the model linearization and predictive uncertainty components.
## Contributions

1. Function-Valued Gaussian Processes (FVGP): Probabilistic currying and linearized uncertainty quantification.
2. Fourier Neural Operators (FNO): Case study for PDE learning tasks.
3. Bayesian Methods: Integration of Laplace approximations and Gaussian belief propagation.
4. Evaluation Pipeline: Verification of scalability and efficacy of predictive uncertainty models.
