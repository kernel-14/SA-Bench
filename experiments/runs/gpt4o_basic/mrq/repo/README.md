# MR.Q - Towards General-Purpose Model-Free RL

This repository contains the reproduction of the MR.Q framework, a general-purpose model-free reinforcement learning algorithm. Below is the current status of the implementation:

## Implemented Components
- [ ] MR.Q Algorithm
  - [ ] Embedding functions (f_ω, g_ω)
  - [ ] Reward, dynamics, and terminal loss
  - [ ] Value and policy updates
- [ ] Benchmarks
  - [ ] Gym-Locomotion
  - [ ] DMC-Proprioceptive
  - [ ] DMC-Visual
  - [ ] Atari
- [ ] Design Study and Evaluation

## Running the Code
Instructions for running the code and reproducing experiments will be provided once implementation progresses sufficiently.

## Notes
The implementation strictly follows the algorithm and experimental design described in the MR.Q paper. Some fine-grained details may require further estimation where unexplained in the main body.
