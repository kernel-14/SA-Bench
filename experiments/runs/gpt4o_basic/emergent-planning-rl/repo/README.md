# README

## Overview
This repository reproduces the main contributions of the paper "Interpreting Emergent Planning in Model-Free RL". It investigates planning behaviors and concept representations in Sokoban-playing DRC agents using linear probes and concept-based interventions.

### Paper Contributions
1. **Probing for Planning-Relevant Concepts:** Implementing linear probes to decode square-level concepts from agent states.
2. **Investigating Plan Formation:** Visualizing agent’s internal multi-step planning processes.
3. **Confirming Behavioral Dependence through Interventions:** Demonstrating causal influence of concept representations on agent behavior.

## Structure
- `src`: Contains Python scripts for probing, interventions, and visualization.
- `configs`: Houses configuration files for experiments and model setups.
- `experiments`: Includes experimental outputs and probe results.
- `figures`: Visual artifacts depicting concept representations and interventions.
