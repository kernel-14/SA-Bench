-e # Improved Convergence Rate for Diffusion Probabilistic Models

## Overview
This repository contains the implementation of core theoretical contributions described in the paper titled 'Improved Convergence Rate for Diffusion Probabilistic Models'.

## Contents
1. src/forward_process.py: Implements the forward diffusion process.
2. src/reverse_process.py: Implements the reverse process with score function.
3. src/sampler.py: Implements the randomized midpoint sampling algorithm.

## How to Use
1. Forward Process: Use the forward_process function.
2. Reverse Process: Use the reverse_process function
