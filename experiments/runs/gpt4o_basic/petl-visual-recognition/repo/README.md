# Replication of Lessons Learned from a Study of PETL in Visual Recognition

## Objectives and Framework
This repository aims to replicate the key contributions of the paper that focuses on systematically evaluating Parameter-Efficient Fine-Tuning (PEFT) methods in visual recognition.

### Key Contributions to Replicate:
1. Implementation of major PEFT methods like LoRA, Adapters, Prompt Tuning, etc.
2. Systematic evaluation on datasets like VTAB-1K, CIFAR-100, RESISC, etc.
3. Insights into complementary information and robustness shown by PEFT methods.

## Implementation Notes

### Structure
1. **Models:** Contains implementations of PEFT methods like LoRA, Adapters, Prompt Tuning.
2. **Configs:** Documents hyperparameters for optimizer tuning and method-specific setups.
3. **Datasets:** Descriptions and setup details for VTAB-1K, CIFAR-100, ImageNet variants.
